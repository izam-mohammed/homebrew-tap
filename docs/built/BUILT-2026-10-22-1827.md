## In short

A Homebrew tap: macOS and Linux users run `brew tap izam-mohammed/tap` and
install the formula and cask it holds. Both files are written by
GoReleaser when their upstream projects release, and pushed to `main` by
the release bot (`goreleaserbot` in `git log`). Nothing here is built or
run by hand.

## What a person can use

### Installing apps

- `claim` 0.1.0 installs as a formula, macOS and Linux, amd64 and arm64,
  with a `test do` block running `claim --version` (`claim.rb`; commit
  `ffc749e`).
- `penpot-mcp` 0.1.6 installs as a cask, macOS and Linux, arm and intel,
  clearing the quarantine attribute on macOS after install
  (`Casks/penpot-mcp.rb`; commits `463b6bc`, `8de4f06`, `1fe33af`).

### Reading the repository

- A two-line README naming the tap and warning not to hand-edit
  (`README.md`). A banner is open in PR `#1` (`docs/banner`), not merged.

## Under the hood

- **Shape**: `claim.rb` at the root and `Casks/penpot-mcp.rb`, both
  marked "generated by GoReleaser. DO NOT EDIT".
- **Data**: none beyond the formula and cask.
- **Integrations**: GitHub release archives named in each `url`, with
  sha256 hashes.
- **Standards and CI**: none. No `.github/` directory, no workflow, no
  `docs/standards.md`, no `.pre-commit-config.yaml` (`git ls-tree -r
