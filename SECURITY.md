# Security policy

## Supported versions

This tap serves only the latest release of each app, so only that version
gets security fixes. Run `brew update && brew upgrade` before reporting.

| Package | Kind | Source repository |
|---|---|---|
| `claim` | formula (`claim.rb`) | [claim-your-code](https://github.com/izam-mohammed/claim-your-code) |
| `penpot-mcp` | cask (`Casks/penpot-mcp.rb`) | [penpot-mcp](https://github.com/izam-mohammed/penpot-mcp) |

## Reporting a vulnerability

Please do not open a public issue, pull request or discussion for a
security problem.

Report it privately through GitHub:
[Report a vulnerability](https://github.com/izam-mohammed/homebrew-tap/security/advisories/new)
(the "Security" tab, then "Report a vulnerability").

Helpful details:

- the package, its version and your platform (macOS or Linux, arm64 or
  amd64)
- what is wrong: for example a download URL that points somewhere it
  should not, or a checksum that does not match the release
- the smallest steps that show it

## What happens next

This is a project with one maintainer, so there are no guaranteed response
times. The aim is to acknowledge the report, agree on how serious it is,
fix it in the source repository's release, and publish a GitHub security
advisory that credits you (unless you would rather not be named).

## Scope

In scope: the formula and cask files in this tap, their download URLs and
their checksums. They are generated by GoReleaser from each app's release,
so a fix lands there and is never hand-edited here. A problem in an app
itself belongs to its own repository's security policy (table above).
